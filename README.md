# Deki Audio

Documentation: https://dekiengine.github.io/deki-audio/ (components and properties, generated from the code)

Audio playback peripheral interface for the Deki Engine, with a MAX98357 (I²S) backend.

Part of the [Deki Engine](https://github.com/dekiengine/deki-engine) package ecosystem.

## Installation

Install via the Package Manager inside the Deki Editor.
